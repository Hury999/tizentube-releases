# TizenTube for Android — download

A YouTube client for Android with background playback, a music mode, SponsorBlock and more.

## Download

**[Download the latest APK](https://github.com/Hury999/tizentube-releases/releases/latest/download/TizenTube.apk)**

All versions: [Releases](https://github.com/Hury999/tizentube-releases/releases)

## Install

1. Open the link above on your Android phone and download `TizenTube.apk`.
2. Open the downloaded file. If asked, allow "Install unknown apps" for your browser.
3. Tap **Install**.

No GitHub account is needed.
